# Pamir Runner

**Pamir Runner** — мобильный браузерный раннер в духе бесконечных забегов, с атмосферой горного Таджикистана.

## Запуск на Android
1. Распакуйте архив.
2. Для быстрого тестирования откройте `index.html` в браузере (некоторые файловые браузеры ограничивают функции).
3. Для публикации загрузите все файлы в корень GitHub-репозитория.
4. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
5. Через несколько минут сайт будет доступен по адресу GitHub Pages. HTTPS позволит добавить сайт на главный экран через меню браузера.

## Управление
- Влево/вправо: кнопки, свайп или клавиши ← →
- Прыжок: кнопка ▲, тап по полю или ↑ / пробел
- Скольжение: кнопка ▼ или свайп вниз
- Пауза: кнопка Ⅱ или Escape

## Что уже реализовано
- Адаптивная сцена с перспективой, горами, дорогой и персонажем.
- Три дорожки, препятствия разных типов, прыжки и скольжение.
- Монеты, расстояние, рекорд в `localStorage`, звуковые эффекты.
- Сенсорное управление, клавиатура, пауза и перезапуск.

## Важно о 3D и онлайн-режиме
Это рабочий **2.5D-прототип**: сцена рисуется на Canvas с перспективой, но не использует полноценный 3D-движок. В текущей версии нет онлайн-мультиплеера или сервера. Их можно добавить отдельным этапом (например, Three.js для 3D и Supabase для аккаунтов/таблицы лидеров); для реального мультиплеера потребуется серверная логика и дополнительная разработка.
